Sistema web Tienda Nova

Aplicación académica para gestionar periféricos, clientes, proveedores y facturas mediante Flask, PostgreSQL, autenticación y operaciones CRUD.

Ver repositorio Conocer el sistema

Esta página es una demostración estática. El backend Flask y PostgreSQL funcionan localmente y en Render.

Buenas prácticas

Modelo relacional

Cinco tablas almacenadas en PostgreSQL y dos relaciones principales de uno a muchos.

TablaClave primariaRelaciónUso
usuariosid—Autenticación
proveedoresid_proveedor1 → N productosCRUD
productosid_productoFK id_proveedorCRUD + JOIN + WHERE
clientesid_cliente1 → N facturasCRUD
facturasid_facturaFK id_clienteCRUD + JOIN

Módulos administrativos

01Periféricos y proveedor relacionado
02Clientes y cantidad de facturas
03Proveedores y productos asociados
04Facturación y cliente relacionado
El acceso administrativo exige iniciar sesión. Todas las operaciones de escritura usan formularios Flask-WTF, validación y protección CSRF.
